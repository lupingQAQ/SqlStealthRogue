# Security Policy

## Authorized Use Only

SqlStealthRogue is a dual-use security testing tool, published for **authorized penetration testing, security research, and education**. By installing or using this tool you represent that:

1. You have **written authorization** from the owners of every system you test with it.
2. You will comply with all applicable local, national and international laws.
3. You understand that unauthorized access to computer systems is a crime in virtually all jurisdictions.

## Prohibited Uses

- Testing any system without the owner's explicit written permission
- Data theft, exfiltration of personal data, or privacy violations
- Any destructive activity (DoS, data corruption, service disruption)
- Use as part of ransomware or other criminal operations

## Reporting a Security Issue in This Tool

Found a vulnerability in SqlStealthRogue itself? Please report responsibly:

1. **Do not open a public issue** for security-relevant findings.
2. Use GitHub's **private vulnerability reporting** (Security → Report a vulnerability), or email the maintainer directly.
3. Include: affected version/commit, reproduction steps, impact assessment.
4. We aim to respond within 72 hours. Please allow up to 90 days for coordinated disclosure before publishing.

## Scope of Support

Engines marked as "not lab-verified" in the README matrix ship community-classic payloads that were hand-checked but not tested against live engines. Treat their output accordingly and report discrepancies via issues — mislabeled capability claims are treated as bugs.
